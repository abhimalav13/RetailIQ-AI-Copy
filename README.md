# RetailIQ AI – Smart Retail Analytics & Business Decision Support

RetailIQ AI is an interactive retail analytics application designed to help businesses understand sales performance, identify product trends, analyze markets, and forecast future revenue.

Built using Python and Streamlit, this project transforms retail transaction data into meaningful business insights through interactive dashboards and analytical tools.

## Key Features

- **Business Overview:** Monitor key business metrics such as total revenue, orders, customers, and average order value.
- **Sales Analytics:** Explore monthly sales trends and revenue performance.
- **Product Intelligence:** Identify top-performing products and analyze product revenue.
- **Market Analysis:** Compare revenue performance across countries.
- **Sales Forecast:** Generate a 30-day revenue forecast using Holt-Winters Exponential Smoothing.
- **AI Business Advisor:** Get automated, rule-based business insights by asking questions about the dataset.
- **Data Upload:** Upload your own retail dataset in CSV or Excel format.

## Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Statsmodels

## Dataset

The project uses the UCI Online Retail dataset, containing historical retail transactions from a UK-based online retailer.

The dataset includes invoice details, products, quantities, transaction dates, unit prices, and customer countries.

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/abhimalav13/RetailIQ-AI-Copy.git
```

2. Open the project folder:

```bash
cd RetailIQ-AI-Copy
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the application:

```bash
streamlit run app.py
```
